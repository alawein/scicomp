# Documentation roadmap

The language-specific module READMEs use this page as the shared backlog for
documentation that still needs to be written. Keeping the backlog here avoids
copying the same placeholder text across the Python, MATLAB, and Mathematica
surfaces while leaving each module README as the entry point for its own
implementation.

## How to use this roadmap

Work through a module's entries in the order below. When an entry is complete,
replace its link in the module README with the resulting topic-specific
documentation; keep platform-specific behavior and requirements in the
language-specific README rather than duplicating them here.

## Work items

For every module and language surface, track:

- [ ] **Theory background** — mathematical foundations, assumptions, and
  notation.
- [ ] **Implementation overview** — algorithms, numerical trade-offs, and
  supported options.
- [ ] **Canonical problems** — representative problems and expected use cases.
- [ ] **Platform-specific notes** — installation, performance, limitations, and
  cross-language differences.
- [ ] **References** — primary literature, standards, and authoritative
  external documentation.
